# PixNexus Gallary

Android 云图库：在手机内直接接入百度网盘，授权后选择文件夹，通过本地索引、缓存和自动扫描展示照片。原图保留在用户网盘中，App 直接请求百度接口。

### 0.5.1 启动恢复

- 冷启动先恢复本地索引和废纸篓过滤，再显示图库，避免空图库与连接提示闪动。
- 最近成功扫描的时间从 Room 恢复，60 秒内重启不重复扫描；已有照片的自动同步静默执行，不插入进度条或移动照片区域。
- 网格、瀑布流和列表按图库来源、相册、布局保存浏览锚点与偏移，退出后重新打开恢复到原位置。首屏已缓存缩略图进行限时解码预热，启动不等待网络。
- 保存已知图片比例，减少瀑布流重启后的高度跳动；图片缓存命中时关闭交叉淡入。
- 本轮验证见 [0.5.1 启动恢复验证](docs/VALIDATION_V051.md)。

- 设置页支持自动备份、废纸篓、主题与语言、缓存维护、移动数据控制和隐私政策。
- 自动备份支持手机相册选择、包含全部相册、包含视频、独立网盘目标目录和移动数据开关。默认关闭；开启后通过 WorkManager 安排上传，默认仅非计费网络执行。
- 手机媒体通过百度预创建、4 MB 分片上传和创建文件流程上传；成功后记录去重标识，不覆盖同名云端文件。备份文件名附加稳定标识，避免不同相册同名照片冲突。
- 废纸篓为本机图库移除记录，30 天内可恢复。不会删除网盘原文件；到期后不可从 App 废纸篓恢复，本机仍隐藏该文件。
- 主题支持跟随系统、浅色、深色；设置页与主要浏览页面支持跟随系统、English、简体中文，选择持久化保存。
- 文件同步和原始内容下载分别受移动数据开关控制；已缓存原图不受网络开关影响。
- 缓存维护支持清除文件缓存、清除本机浏览记录、刷新目录、重建本地文件名/目录 FTS 索引。当前尚无搜索页面。

0.5.0 的验证范围和限制见 [设置与备份验证](docs/VALIDATION_V05.md)。以下为沿用的图库能力。

- 移除旧的外部服务连接入口、实现、配置读写和模拟工具，只保留百度网盘接入；升级保留已有百度授权、所选目录和缓存。

- 百度授权码卡片支持点击复制并显示完成反馈；启动图标替换为蓝色 CloudGallery 图标，并提供 Android 自适应图标资源。

- 全新浅色图库界面：冷白与蓝色、轻玻璃面板、悬浮底部导航；缩小顶部信息区，把更多空间留给照片。
- 三列自适应网格、保留比例的瀑布流、信息列表；双列相册封面、分组设置、深色原图查看器。授权和文件夹选择采用统一视觉样式。

- 百度设备码授权页面、身份读取、文件夹浏览及分页、选择后自动进入图库。
- 授权与目录通过 Android Keystore AES-GCM 加密保存；会话自动刷新，重启可恢复。
- 启动读取本地索引，同时后台扫描；进入前台时自动检查，间隔至少 60 秒。WorkManager 每小时安排后台更新，实际执行受系统、网络、电量条件影响。
- 递归分页索引 JPEG、PNG、WebP、HEIF、HEIC，持久化扫描队列。完整扫描成功才移除消失的索引；失败保留已有照片，不删除网盘文件。
- 按文件修改日期展示时间轴，按目录分相册。详情支持翻页和双指缩放。
- 照片页和相册内可切换网格、瀑布流、列表，布局选择保存在设备上。瀑布流按缩略图实际比例展示，列表展示文件名、目录和日期。
- 修复百度原图 HTTP 403：下载链接补充当前访问令牌，保留签名参数并校验下载域名。
- 网格优先较小的百度缩略图；按滑动方向预取附近 24 张，保留重叠范围内的请求。Wi-Fi 后台提前缓存最近最多 1000 张缩略图。
- 缓存命中直接显示，重复请求合并，滑出预取范围后取消网络请求；可见缩略图、附近预取、后台缓存、原图各有独立并发限额（6 / 2 / 1 / 2）。
- 详情先显示缓存预览再加载原图。无缩略图时，非计费网络按需生成小图；计费网络需要点击详情加载原图。
- 缓存预算 256 MB，空间不足时批量淘汰；已缓存图片可离线显示。单张缩略图下载上限 12 MB、原图 64 MB。

## 构建

Android Studio 打开本目录。AGP 8.7.3、Gradle 8.10.2、Kotlin 2.1.0、Compose BOM 2024.12.01；minSdk 26、compileSdk/targetSdk 35。本机使用 Android Studio JBR 21 验证。

```powershell
.\gradlew.bat assembleRealDebug assembleMockDebug
.\gradlew.bat testRealDebugUnitTest lintRealDebug
```

产物：`app/build/outputs/apk/real/debug/app-real-debug.apk` 和 `app/build/outputs/apk/mock/debug/app-mock-debug.apk`。包名分别为 `com.cloudgallery.app` 与 `com.cloudgallery.app.mock`，不会共用授权和索引。

在被忽略的 `local.properties` 配置 `sdk.dir`，百度配置入口为 `baidu.appKey` 和 `baidu.secret`，不要提交真实凭据。APK 内配置无法作为保密的服务端密钥，正式发布需确认百度允许的移动端授权及密钥交换方案。详见 [百度接入说明](docs/BAIDU_INTEGRATION.md)。

准备真实授权请按 [真实授权接入步骤](docs/REAL_AUTH_SETUP.md) 填写配置，执行 `:app:verifyBaiduConfig :app:assembleRealDebug`。配置检查不会输出密钥，也不替代用户在百度页面授权。
