# 0.6.11 小红书导入与图库验证

验证：2026-09-27；整理：2026-09-28。versionCode 23，应用名和包名不变。

## 已复现的故障

真实小红书双图笔记，第 1 张成功，第 2 张出现完整尺寸校验失败。公开页面标注 3366×2736，直接 fileId 图源实际返回 2560×2081 PNG（9,253,105 字节）；页面预览地址则返回 1080×878 JPEG、240×195 JPEG。旧规则要求下载尺寸不小于页面元数据，误拒了源站提供的高清版本。

修正后，完整尺寸及 EXIF 方向规则继续适用；仅直接 fileId 来源允许长边至少 2048、至少 200 万像素、比例误差不超过 1%、不超页面尺寸的高清版本。页面提供的备用地址没有缩小尺寸例外。仍拒绝小图、裁剪比例不同和超过 1.5 亿像素的图片。保留源文件，不放大、不转码；高清版本不保证达到页面宣称的原始像素数。

## 修改范围

- 分享点击前刷新语义树，页码元数据短暂消失时等待动画；明确页码变化仍终止。复制后短暂等待已验证的小红书窗口恢复。继续拒绝朋友圈、混合容器和坐标猜测。
- 下载中账户解密、任务状态和网络策略检查改为每 500ms 一次，保存、上传阶段边界强制检查；协程取消仍在每次读取时检查。
- XhsSource 的可取消请求覆盖响应体读取，取消慢下载会关闭连接、清理不完整文件；HTTP 408/429/5xx 可以重试。
- 直接图源无效时仅尝试当前 imageList 项明确提供的最多两个备用地址，保留 CDN 参数，检查域名与尺寸。
- Worker 条件更新不覆盖 cancelled/completed/failed，取消不覆盖 completed，暂停不复活已结束任务。
- 队列接收轻震 12ms、成功短震 30ms、失败双震；遵循震动开关和系统设置。任务记录增加时间。已保存链接但调度暂未完成时保留恢复入口。
- 图库并行请求预览与原图，显示原图加载提示；Android 9+ 使用 ImageDecoder 生成长边最多 768 的预览，支持 HEIF 和方向，Android 8 保留 BitmapFactory/EXIF 路径。
- 导入目标在当前图库范围之外时，不触发无关目录的全量扫描。

## 验证结果

- JVM：83 项测试，0 failures / 0 errors。覆盖分享目标拒绝、页码、域名、备用地址参数、取消慢响应、高清尺寸规则等。
- real/mock Debug、mock AndroidTest 构建成功；lint 0 errors / 14 warnings。
- importPipeline：模拟直接来源返回 8×8 小图，3 个排队任务都改用明确的完整图源完成；重复图片去重，云端只有两张不同图片。
- importRecovery：交接、取消、完成状态竞争通过，旋转 JPEG 预览为 16×32，小图继续拒绝。
- captureWindow：焦点剪贴板到持久化及 WorkManager 交接通过；故意不匹配账户在请求图源前停止。
- heif：1440×960 HEIF 元数据、解码、索引和有界预览通过。
- galleryFeatures：数据库升级、空相册持久化、扫描失败保留缓存、完整扫描清理失效目录、PNG/JPEG/HEIC 保存字节一致及失败清理通过。
- 真实小红书：先复现第二张尺寸错误，修正后首次约 3.17s 成功，两次重复约 1.75s / 1.33s 成功并复用同一手机相册 URI；另一篇单图笔记约 1.77s 成功。修正后连续 4 次通过，没有进入朋友圈编辑页。
- 分享操作至请求取链接窗口约 250–400ms。总耗时包含真实图源下载及模拟网盘上传，不能据此推定真实百度上传速度。
- 系统 Vibrator Service 输出确认本轮 12ms 接收、30ms 成功和 [0,70,100,70] 失败双震请求；不能由模拟器确认实体手机震感。
- 新导入 JPEG/PNG 在图库显示、查看和下载成功；名称升序、瀑布流及缓存重启恢复通过。

测试环境是 emulator-5554 / Android 9 / 小红书 9.33.4。小米 13 Android 16、努比亚 Z50 Ultra Android 14 未连接，本轮没有上传真实百度账户。不能承诺所有厂商系统及未来小红书版本均无故障。9 月 28 日整理记录时模拟器已断开，以上是此前已完成的验证，并非断开后重新运行。
