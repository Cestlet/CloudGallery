# CloudGallery 0.4.2

## 连接路径与删除范围

百度网盘一直通过 BaiduProvider、BaiduOAuth 和 BaiduSession 直接连接百度 HTTPS 接口。此次删除独立的旧连接入口、服务请求实现、地址/令牌/目录密码配置、启动时的旧来源回退、专用测试与模拟工具。

共享的文件模型、路径规范化和缓存标识算法保留在 StorageProvider.kt。账户存储改为 BaiduAccountStore；原有 preference 文件名、Keystore 别名和加密格式保持兼容。升级只清理退役的 record 和 active 字段，保留 baidu 加密记录。

正式包禁止明文 HTTP；本机模拟包单独允许 HTTP，继续使用 127.0.0.1 假服务。

## 自动同步行为

- 启动恢复已选目录后立即扫描。
- 回到前台，距上次同步超过 60 秒且没有授权或目录选择操作时检查更新。
- 选择目录后立即扫描。
- 后台每小时安排扫描，要求联网、电量不低；初次后台任务延迟一小时，系统可以进一步延迟。
- 手动同步和暂停继续可用。

前台的 60 秒阈值用于限制重复启动，不代表持续停留在页面时每分钟轮询。同步为读取网盘变化、更新图库索引和缓存，不会自动上传手机照片。
