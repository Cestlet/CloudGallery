# 0.6.7 图库上传与排序

日期：2026-09-27。

## 功能

- 照片页、相册页右上角增加上传入口。系统文件选择器支持多选图片，不额外申请全相册读取权限。
- 上传前可选择网盘目标文件夹，默认图库根目录或当前相册，可单独允许移动数据；关闭时等待非计费网络。
- WorkManager 持久化后台批次；每项完成后持久化记录，失败重试跳过已完成项。支持进度、失败原因、重试和取消。取消不删除已上传文件。
- 文件名添加批次标识，保留 JPEG/PNG/WebP/HEIF/HEIC 扩展名，避免覆盖同名云端文件。上传完成后安排符合图库同步网络偏好的索引更新；目标在图库范围以外时需切换图库目录查看。
- 上传临时文件和成功批次清理；失败批次保留重试记录，关闭失败状态时清理记录与不再使用的 URI 授权。
- 排序菜单：修改时间新到旧/旧到新、名称 A→Z/Z→A、大小大到小/小到大。以网盘修改时间排序，不以 EXIF 拍摄时间排序。
- 排序适用于网格、瀑布流、列表和相册内图片，原图左右浏览沿用当前排序。名称/大小排序不按日期重新分组；时间排序保留日期分组。
- 排序偏好和每种排序的浏览位置持久化；相册入口保持文件夹名称顺序。

## 验证

- real/mock Debug 构建通过；72 项 realDebug JVM 测试通过，0 failures / 0 errors；realDebug lint 0 errors / 12 warnings。
- 雷电 Android 9 模拟器通过系统选择器多选两张 PNG，选择 /Photos/Nested 上传；图库数量 204→206，目标相册 3→5。
- 新测试服务器故障注入：首张成功后第二张 precreate 返回错误，UI 显示已完成 1/2。解除故障并点击重试，最终创建和分片计数均为 2，未重传已完成项。
- 测试服务器按实际上传字节提供原图，无通用缩略图替代；上传的 PNG 在云端图库原图查看器正常显示。
- 名称排序跨日期、跨文件夹平铺；大小排序将真实较大的 HEIF 样本排在前方；强制停止 App 再打开后保留大小排序、列表布局。
- 子相册保留排序菜单，时间排序显示日期分组；移动数据选择在进入目标目录选择后保留。
- 测试只操作本地模拟百度接口，没有上传到真实百度网盘；小米 13 / Android 16 尚未验证本轮新增功能。
- 本轮没有修改小红书快捷导图逻辑，既有新笔记偶发未取得新链接的问题仍未解决。
