# CloudGallery 构建大纲

## 当前产品目标

Android 云图库直接连接百度网盘。用户在手机中授权账号、选择照片文件夹后，即可通过本地索引、缓存和自动同步浏览照片。图片保留在用户网盘内。

## 已实现架构

Android 图库 UI → Room 本地索引与 PhotoCache 图片管线 → BaiduProvider → 百度官方 HTTPS 接口。

- 百度设备码授权、点击复制授权码、加密保存会话、自动刷新令牌。
- 浏览目录并选择图库范围，递归分页扫描，按文件修改日期展示时间轴。
- 三种照片布局、目录相册、原图翻页、双指缩放、加载失败重试。
- 可见图片优先，附近 24 张预取，非计费网络后台缓存最近最多 1000 张缩略图。
- 缓存预算 256 MB；缓存预览先显示，原图按需加载。
- 扫描成功后比较删除；失败保留本地索引，不删除网盘文件。

## 自动同步

1. 冷启动恢复授权与目录，立即读取本地索引，并自动开始扫描。
2. 回到前台时，距离上次同步超过 60 秒才检查更新；这不是每分钟轮询。
3. 选择新目录后立即自动扫描。
4. 后台通过 WorkManager 每小时安排同步，需联网且电量不低。系统可以延迟执行，强制停止 App 后也不能保证后台执行。
5. 同步按钮保留为立即触发入口，用户不必每次点击。
