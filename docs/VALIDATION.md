# 0.1.0 验证记录

日期：2026-09-27。

## 构建

使用本机 Android Studio JBR 21、Android SDK 35、Gradle 8.10.2。

`gradlew.bat --offline assembleDebug lintDebug --no-daemon` 成功，生成 debug APK。lint 为 0 errors、7 warnings，包含依赖版本更新提示和备份规则相关提示。当前版本复用已缓存依赖，后续工程升级单独验证。

## 模拟器验证

在已有 Pixel_8 模拟器安装最终 APK，成功启动。

- 日期网格展示 72 个本地示例，首日 9 张。
- 三个目录相册，每个 24 张；进入“山间旅行”后按日期展示每组 3 张。
- 从第一张进入详情，滑动到第二张，文件名及计数变为 IMG_1001.jpg、2 / 72。
- 连续点击后继续滑动至第三张，文件名及计数变为 IMG_1002.jpg、3 / 72。
- 系统返回键返回图库，可切换相册页和照片页。
- AndroidRuntime 日志未发现运行异常。

测试发现并修复了缩放手势拦截普通翻页的问题。双指缩放和缩放后的拖动已实现，但本次 adb 单指交互没有验证实际多点触控，需真机或多点注入进一步验证。

截图和界面层级文件保存于 screenshots/。真实 Alist、持久索引、图片缓存、扫描恢复以及大型图库性能均不属于本次验证范围。
