# 0.6.3 自动导图紧急停用

用户报告双音量键后进入朋友圈分享。尚无该手机节点树或日志，无法确认具体误触位置，也不能确定是否完成发布。

代码检查发现旧流程含右上角位置推断，并将复制链接节点向上寻找可点击父节点，再通过手势点击其中心；父节点可能含多个分享目标，节点和坐标在动画期间也可能变化。此前没有真实小红书正常分享链路验证，不能将该流程继续作为可用功能发布。

处理：完全删除 QuickImportService 的菜单操作与按键触发实现，保留空服务类兼容旧组件名；Manifest 禁用该组件，XML 不声明手势或按键过滤能力；偏好读取及写入均强制关闭快速导图，旧启用值不再生效，上传 worker 按关闭状态暂停。设置显示已暂停，没有重新开启入口。保留网盘授权、目录、本地保存偏好及任务历史。

该版本是停止误操作的修复，不代表无感导图已经实现。不操作用户微信、朋友圈或已有发布内容；需由用户检查并处理实际分享结果。
