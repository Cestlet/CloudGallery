# CloudGallery 0.5.0 设置与备份

## 实现范围

设置使用分组卡片：百度连接、自动备份、废纸篓、外观与语言、缓存、网络、关于。选择持久化到本机；主题即时生效，主要页面和设置对话框支持中英文。

自动备份默认关闭。用户授予完整媒体读取权限后，可以备份全部相册或选定相册，选择是否包含视频、是否允许计费网络、独立的百度目标目录。Android 13+ 分别申请照片/视频读取权限；较早系统申请 READ_EXTERNAL_STORAGE。没有权限、目录或相册时不能启用。WorkManager 每小时检查，联网且电量不低时执行，任务实际时间由系统安排。关闭备份会取消任务，上传请求支持取消，已上传文件保留。

上传参考百度维护的 [预创建接口](https://github.com/baidu-netdisk/baidu-drive-sdk-go/blob/main/baidudriver/api/upload_precreate.go)、[分片接口](https://github.com/baidu-netdisk/baidu-drive-sdk-go/blob/main/baidudriver/api/upload_slice.go)及[创建接口](https://github.com/baidu-netdisk/baidu-drive-sdk-go/blob/main/baidudriver/api/upload_create.go)。上传前按 4 MB 块计算 MD5，仅发送服务端缺少的块，完成后记录成功标识。文件名附加稳定标识，云端同名时拒绝覆盖。大视频不整体加载到内存中。每轮最多上传 30 个文件，剩余文件通过 WorkManager 重试继续处理。

废纸篓为本机图库移除与恢复。图片查看器提供确认移除，30 天内可恢复；原图不从百度网盘删除。到期后只失去 App 内恢复入口，仍保留本机隐藏记录，清除应用数据会清除这些记录。

清除文件缓存会取消图片请求及后台预热，阻止清理前的下载重新写入缓存，并清除 Coil 内存缓存。浏览记录和文件名/目录 FTS 索引存储在独立 SQLite 数据库。重建搜索索引不触发上传，当前尚未提供搜索页面。

文件同步默认要求非计费网络，扫描每页前检查网络偏好。原始内容下载单独检查移动数据偏好，已缓存原图仍可直接显示。备份移动数据控制独立于这两个开关。

## 验证环境及结果

- 本机 JBR 21、Gradle 8.10.2；real/mock Debug 构建成功。
- 23 项单元测试，0 失败；包括新增的缺失分片上传、秒传分支、分片校验失败不创建文件、配置检查失败不发送数据。
- lint 0 错误、12 条提示。依赖更新与既有规则提示仍保留。
- Android API 28 模拟器：主题切换、English/简体中文切换和重启持久化通过；截图发现的深色标题及状态栏对比度问题已修复。
- 独立备份目录 `/Other`，图库仍为 `/Photos`。选择一个测试相册，把单张测试 PNG 上传到本机假服务；一次分片上传、一次创建成功。再次备份未重复上传；验证后关闭备份。
- 图片移除后进入废纸篓，显示剩余保留天数，恢复后回到图库。
- 文件缓存清理、浏览记录清理和重建搜索索引通过 UI 验证；导出 SQLite 及其 WAL 后核对：history=0、search=202、trash=0。
- 更新后的 `tools/smoke-ui.ps1` 验证三种布局、重启保存、原图翻页、相册返回和图库目录选择取消。

截图与本机验证文件位于被忽略的 `app/build/tmp/settings`。

## 尚未验证及限制

- 本轮没有向真实百度账号上传文件；真实应用的写入权限、允许目录和大视频上传需用用户账号另行验证。
- Android 13/14 的媒体授权界面、长时间后台执行、30 天真实时间流逝、设备断网及电池变化尚未做真机覆盖。
- 每轮上传有数量上限；大量历史照片的完整备份需要多轮后台任务，可能被系统延迟。
- 本机去重记录在清除应用数据后丢失。云端同名不覆盖，因此云端已有同名文件时会报告失败；上传成功但成功记录写入前被系统终止，也可能遇到该冲突，需要人工处理。
- English 覆盖设置与主要浏览文案；部分无障碍描述、网盘提供的名称和详细错误仍可能使用中文或原始名称。
- 废纸篓仅影响这台设备中的 App 图库；不是百度网盘回收站。
