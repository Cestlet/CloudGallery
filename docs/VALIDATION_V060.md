# 0.6.0 快速导图验证

验证日期：2026-09-27。模拟器 Android 9 / API 28，小红书 9.33.4。

## 实现

设置 → 快速导图提供功能开关、无障碍授权入口、独立网盘目录、同时保存到手机相册、移动数据、振动和最近任务。默认关闭功能和本地保存。目录与本地保存设置只影响新任务。

双音量键在 250 ms 内重叠按下触发一次；仅在小红书图片页处理。读取图片页码，按节点位置打开分享菜单并复制链接，通过短暂前台透明 Activity 读取新剪贴板内容。解析公开页面并核对笔记、页码、图片数量和尺寸；失败不保存其他图片。图片不转码，使用私有临时文件和百度分片上传；本地保存开启时发布到 Pictures/CloudGallery。

## 已通过

- real / mock Debug APK 构建，38 项单元测试全部通过。
- real lint：0 errors / 12 warnings；mock lint：0 errors / 3 warnings。
- 模拟器硬件输入事件验证双键顺序、长按防重复和超时不触发。
- 模拟图源 → 实际下载、尺寸检查 → 模拟百度分片上传完成两张图片；目标目录 /Other，服务端 creates=2、uploads=2。
- 本地保存关闭的任务 localUri 为空，无新增对应相册文件；开启的任务生成 content://media/external/images/media/1020，PNG 197277 字节，上传和保存均成功。
- 再次导入第二张图片复用同一相册 URI，服务端 creates 仍为 2；成功后剪贴板链接从任务记录清除，私有导图目录为空。

- real 合并 Manifest 无 QuickImportFixtureActivity / XhsSourceProbeService；诊断和模拟入口仅包含在 mock 构建。

## 尚未验证

当前模拟器小红书多篇笔记原生分享提示“该笔记暂时不支持分享”，旧公开链接深链出现加载空白。已验证服务失败时记录原因，不上传。完整的“小红书双键 → 复制链接 → 实际外网取图 → 真实百度上传”未通过，不应宣称已实机可用。

此前桌面端公开页面图源研究得到全尺寸 PNG / JPEG；不能据此保证所有笔记都支持，也不能保证与作者原始文件字节相同。当前模拟器外网取图未通过，成功上传实验使用项目自有测试图片和模拟网盘，未操作真实网盘。

Android 10+ 前台剪贴板读取、分区存储，以及实体手机硬件组合键和后台限制仍需实机验证。复制链接会替换剪贴板，系统音量浮层可能短暂出现；公开页面变化、登录要求或笔记禁止分享会导致导入失败。
