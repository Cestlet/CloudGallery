# 0.6.4 分享目标误触修复

用户确认没有发布朋友圈，只是进入编辑界面，并要求恢复修复功能。

## 修复

- 删除所有坐标点击、手势派发、右上角位置推断及任意祖先节点点击回退。无障碍 XML 保持 canPerformGestures=false。
- 仅对分享 / Share、复制链接 / Copy link 的独立语义动作执行 ACTION_CLICK。候选必须可见、可用、属于小红书，且支持 ACTION_CLICK。
- 专用包装按钮子树最多 12 个节点，只允许目标标签且只有一个可点击动作；含朋友圈、微信、其他标签或独立可点击子项的公共容器被拒绝。多个候选也拒绝。
- 执行动作前刷新目标、再次核对其标签、子树及当前窗口，失效或不支持动作即失败，没有坐标回退。不会操作微信窗口。
- 分享后最多 1.2 秒寻找明确复制按钮，复制后仅在已确认的复制菜单仍存在时返回关闭菜单，然后通过前台焦点窗口读取新剪贴板。保留 0.6.2 的剪贴板短暂重试及通知用途失败双震。
- 首次升级将旧快速导图启用值置为关闭，保留目录、本地保存选项和记录，需用户重新主动启用；后续重启正常保留开关。

## 验证

real / mock Debug 构建、real lint 通过，51 项单元测试通过（其中 12 项新增误触回归和 1 项诊断隐私过滤）。覆盖复制链接与朋友圈共享父容器、独立复制按钮、专用包装、其他可点击子项、重复按钮、隐藏/禁用/微信节点、标签不一致、循环和异常树。

模拟器安装升级后快速导图默认关闭，目录 /Other 和本地保存选项保留；界面恢复主动启用入口。源码中不存在 dispatchGesture、坐标或 parent 点击回退。

模拟器中的小红书打开笔记仍异常，未验证真实小红书正常菜单 ACTION_CLICK 和完整上传链路。选择器和构建通过不能等同于实体手机完整导图成功。若小红书没有明确语义标签或未实现按钮无障碍动作，该版会停止并记录原因；不得为兼容而恢复猜坐标。用户手机为小米 13、Android 16、小红书 9.48.0（33cf2ec），与当前模拟器版本不同；该组合尚未实机验证。新增“复制按钮诊断”入口，记录设备/API、阶段及过滤后的节点结构，只保留已知操作标签，未知正文、用户名和链接仅计数不保留。诊断保存在本机，不自动发送。

Android 动作依据：https://developer.android.com/reference/android/view/accessibility/AccessibilityNodeInfo
