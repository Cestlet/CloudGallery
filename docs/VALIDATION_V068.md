# 0.6.8 双音量键兼容修正与诊断

日期：2026-09-27。用户反馈 Z50 Ultra / Android 14 按键无反应；未连接该手机，根因尚未证实。

- 音量按键不再在每个事件前读取小红书窗口并清空组合状态。先识别双键及松开事件，再验证前台小红书；短暂没有根节点时最多等待 240 ms。
- 前台判断只允许明确的 SystemUI 浮窗或短暂无活动根节点；其他前台应用、未知浮窗、无法读取的顶层应用窗口仍拒绝导入。仍只执行既有语义分享/复制按钮，不使用坐标点击。
- 最近 12 条音量事件及识别结果保存在本机。记录服务连接、上下键按下/松开、已识别组合、无小红书前台窗口或已有取链接任务。无其他按键或帖子链接。
- 设置 → 快速导图 → 复制导图诊断：合并按键诊断与既有按钮诊断，并注明按钮信息可能来自上一次导图。
- 组合仍要求 250 ms 内重叠按下，不改变为长按。

验证：real/mock Debug 构建通过，74 项 JVM 测试通过，0 failures / 0 errors；realDebug lint 0 errors / 13 warnings。新增窗口策略与浮窗期间松开后再次识别的测试。模拟版 APK 已安装；本轮未完成真实小红书导图或 Z50 Ultra 设备回归，不能宣称已解决该手机故障。

安装包：exports/PixNexus Gallary-0.6.8.apk，real Debug，沿用开发签名。

用户安装后重新关闭并开启系统中的 PixNexus Gallary 快速导图无障碍服务；在小红书图片页短按双音量键。若仍无反应，复制导图诊断用于区分服务未连接、按键未送达、组合未识别与前台窗口拒绝。
