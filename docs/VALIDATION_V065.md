# 0.6.5 模拟器真实小红书测试

日期：2026-09-27。模拟器 emulator-5554，Android 9 / API 28，小红书 9.33.4。用户实体手机：小米 13，Android 16，小红书 9.48.0（33cf2ec），未连接本机。

## 实测发现和修复

分享图标没有文本和描述，但资源 ID 为 com.xingin.xhs:id/moreOperateIV，类型 android.widget.ImageView，ACTION_CLICK 可打开菜单。适配仅接受此明确 ID 的可见可用叶节点，不接受通用混淆 ID 或位置推断。

复制链接外层 android.widget.Button 不可点击，ACTION_CLICK 返回 false；ACTION_LONG_CLICK 返回 true 但不更新剪贴板。实际可点击目标是它内部的专用 ViewGroup。无障碍服务获得压缩节点树，点击子节点不再包含文字；通过“复制链接”语义 Button 的唯一子分支锚定唯一可点击节点，检查整个分支没有其他标签或点击目标，再调用该子控件 ACTION_CLICK。不会点击外层 Button 或分享整行。执行前重新核对当前完整节点树及窗口。

多图笔记第 2 张页面标注 1920×2560，公开图源实际 2650×3533；原来的相等校验误拒绝高清文件。现在允许宽高都不低于页面标注、比例差不超过 1%、不超过 1.5 亿像素的结果。仍拒绝小图或比例不符的结果，不转码。

## 已通过的真实 App 链路

- 通过模拟器硬件双音量输入触发生产服务，没有使用坐标手势打开或点击分享菜单。
- 单图笔记：307 ms 进入剪贴板捕获；随后真实网络下载 JPEG，上传到本机模拟百度网盘 /Other，并发布手机相册副本 content://media/external/images/media/1111（62448 字节）。
- 重复触发同图：261 ms 进入剪贴板捕获，复用 URI 1111，模拟服务器 uploads / creates 仍为 1 / 1。
- 14 图笔记选择第 2 张：修复尺寸校验后，336 ms 进入剪贴板捕获，上传 /Other 并保存 URI 1112；JPEG 2650×3533、2023854 字节。与独立下载的该笔记第 2 张公开 fileId 图源 SHA256 一致（逐字节一致）。服务器创建文件总计 2。
- 成功后任务 linkLength=0，私有 quick-import 临时目录为空；图库和自动备份目录没有因导图目的地 /Other 改变。
- real / mock Debug 构建和 real lint 通过；60 项单元测试通过，包括误触隔离、实测分享 ID、压缩复制节点及高清尺寸回归。

307 / 261 / 336 ms 是触发到启动剪贴板焦点窗口的服务日志，不代表完整下载上传耗时。源图片下载和上传在后台完成。

## 范围和限制

本次使用真实小红书页面和公开网络图片，上传端仅为本机模拟百度接口，不操作真实网盘。不是之前的项目自有图片图源测试。复用此前用户明确授予的模拟器无障碍授权，旧诊断服务保持关闭。

模拟器 ACTION_CLICK 探针位于 androidTest APK，与用户安装的 real APK 分离。探针曾失败的动作也记录在这里，不能将 ACTION_LONG_CLICK 成功返回视作复制成功。

实体手机 Android 16 / 小红书 9.48 的节点结构和后台窗口限制尚未实测。如果该版本隐藏或改名资源 ID，服务会停止并留下“复制按钮诊断”，不允许回退猜坐标。公开图源变化、登录校验、网络或不支持的图片仍可能失败；本次字节比对仅证明未改动所取公开图源，不证明与作者上传前文件一致。
