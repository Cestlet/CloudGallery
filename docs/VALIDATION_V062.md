# 0.6.2 复制流程和失败震动修复

用户实体手机记录出现“复制后未返回图片页面”“未取得新复制的帖子链接”“取图时离开小红书”，并反馈等待过长、失败无震动。

修复：分享菜单轮询从 100 ms 改为 40 ms，查找上限从 2.5 秒改为 1.2 秒；节点手势从 80 ms 改为 40 ms。复制后若仍存在复制链接菜单，主动返回关闭本次打开的菜单，移除原有最长 2 秒等待。图片页可见时核对页码，后台仍核对图源数量和笔记 ID。活动窗口优先识别小红书，仍禁止选择其他前台应用背后的小红书窗口。

透明焦点窗口不再只读一次剪贴板，最多重试 900 ms，以适应异步复制和焦点交接；仍只接受任务创建后复制的支持域名链接，拒绝旧剪贴板和空内容。失败双震延长为 70/100/70 ms，API 33+ 用 VibrationAttributes.USAGE_NOTIFICATION，旧版用 AudioAttributes.USAGE_NOTIFICATION；保持用户震动开关及系统限制。

验证：real/mock APK 构建及 real lint 通过，38 项单元测试通过。Android 9 模拟器空剪贴板实验记录失败、没有上传，dumpsys vibrator 记录本应用双震 waveform 和 usageHint=5（通知用途）。模拟器无法证明实体手机实际震感，真实小红书菜单和网络完整链路仍待手机验证。未宣称已经实现全程无感或保证实体手机耗时。
